# Portfólio - Desenvolvedor Web

## 📌 Sobre o projeto

Este projeto consiste em uma página de **Portfólio / Currículo Web**, desenvolvida utilizando HTML5.

O objetivo é apresentar informações pessoais, habilidades, projetos desenvolvidos e uma área de contato de forma organizada e utilizando elementos semânticos do HTML.

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## 📂 Estrutura da página

A página está dividida nas seguintes seções:

### Sobre Mim

Apresenta uma foto de perfil, uma pequena descrição do desenvolvedor e suas principais habilidades.

### Meus Projetos

Apresenta uma tabela contendo:

- Nome do projeto
- Tecnologias utilizadas
- Status do projeto
- Link para acesso

Os projetos apresentados são:

- Site de Loja
- Sistema de Cadastro
- Portfólio Pessoal

### Entre em Contato

A página possui um formulário com os campos:

- Nome
- Email
- Assunto
- Mensagem

Também possui um botão para envio do formulário.

## ▶️ Como executar o projeto

1. Baixe ou copie os arquivos do projeto.
2. Coloque a imagem de perfil chamada `perfil.jpg` na mesma pasta do arquivo HTML.
3. Abra a pasta do projeto no Visual Studio Code.
4. Abra o arquivo HTML.
5. Execute pelo navegador ou utilize a extensão **Live Server**.
